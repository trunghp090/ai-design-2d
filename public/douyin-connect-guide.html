Kết nối Douyin trên Edge

Cài tiện ích một lần và đăng nhập Douyin trên Edge. Sau đó mở tool bằng Edge này, dán link rồi bấm Lấy video / ảnh; tool tự dùng phiên Douyin hiện tại.

↓ Tải tiện ích Edge 1.0.3

Cập nhật bản đã cài lên 1.0.3

Bản 1.0.3 sửa lỗi xử lý cookie tuỳ chọn có khoảng trắng, đồng thời báo rõ nguyên nhân lỗi kết nối.

Khi các file trong thư mục tiện ích đã được cập nhật, mở edge://extensions, tìm thẻ AI Design 2D — Kết nối Douyin rồi bấm Tải lại (↻). Sau đó tải lại trang tool, kiểm tra dòng Tiện ích 1.0.3 sẵn sàng, dán link và thử tải.

Nếu thư mục vẫn chứa bản cũ, tải ZIP 1.0.3 ở trên và giải nén thay các file trong thư mục đã cài trước khi bấm Tải lại.

  1. Giải nén file vừa tải.
    Bạn sẽ có thư mục douyin-connect chứa file manifest.json.
  2. Mở trang tiện ích của Edge.
    Dán edge://extensions vào thanh địa chỉ và nhấn Enter.
  3. Bật Developer Mode.
    Tên tiếng Việt là Chế độ nhà phát triển. Chọn Load unpacked / Tải tiện ích đã giải nén, rồi chọn thư mục douyin-connect.
  4. Đăng nhập Douyin trên cùng Edge.
    Mở Douyin ↗. Nếu Douyin yêu cầu quét mã hoặc xác minh, hoàn tất trên trang Douyin.
  5. Tải lại trang tool.
    Vào tab Tải TikTok / Douyin, dán link rồi bấm Lấy video / ảnh. Nút Kết nối Douyin chỉ dùng khi bạn muốn kiểm tra phiên đăng nhập.

Từ lần sau

Chỉ cần mở tool bằng Edge này, dán link rồi bấm Lấy video / ảnh. Tool tự đọc phiên đăng nhập mới mỗi lần lấy bài; không cần bấm kết nối lại hoặc chép cookie.

Khi video hoặc ảnh đã hiện, bấm nút tải và chọn nơi lưu. Tool sẽ tải file sau khi bạn chọn xong.

Tiện ích đọc phiên Douyin và gửi tới tool cho yêu cầu tải của bạn. Phiên không lưu trong tiện ích hoặc trên máy chủ. Bấm Xoá hoặc Huỷ để xoá phiên khỏi tab; lần tải tiếp theo sẽ tự đọc lại phiên trên Edge.

Tiện ích dùng cho riengvnapp.cloud và tool chạy trên localhost:8000. Douyin vẫn có thể yêu cầu xác minh hoặc từ chối một số bài đăng.
